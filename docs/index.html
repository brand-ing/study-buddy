focus

A minimal study timer for Windows. Pomodoro, to-dos, and a heatmap of your streak, all in one small always-on-top window.

Work18:42
Download for Windows

Single .exe · no installer · no admin rights · free and open source (MIT)

Features

  • Pomodoro timerClassic 25/5/15, Deep Work 50/10, Balanced 45/15, or custom.
  • To-do listAdd, check off, drag to reorder, double-click to edit.
  • Task dockA taller scrollable task panel that pops up from the tray.
  • GlanceA tiny draggable timer capsule that fills green as a session runs out.
  • Activity heatmap16 weeks of focus, one square per day.
  • Time-of-day themesSix palettes that shift from sunrise to late night.

First run

Windows may show "Windows protected your PC." focus isn't code-signed yet, so SmartScreen doesn't recognise it. Click More info → Run anyway. The source and the build that produced the .exe are public on GitHub.

The app lives in your system tray. To keep it, move focus.exe somewhere like %LOCALAPPDATA%\focus\ and turn on Launch at login in Settings.
